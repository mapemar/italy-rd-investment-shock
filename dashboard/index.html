Interpretation rules

  • 2020–2026 is the core PNRR implementation window.
  • Budget authorisations, commitments, cash flows, ESA recording and R&D performance have distinct time dimensions.
  • 2027–2028 values in the Treasury return profile are return-to-budget flows, not new PNRR implementation or negative R&D expenditure.
  • For the extended innovation shock, the project applies a 100% proxy to DTF/GTF fund investment commitments/deployment as agreed. This proxy is kept separate from official GERD/BERD and from company R&D actually performed.
  • Funding envelopes and economies are not the same as realised R&D expenditure.

How to use the Data Explorer

  1. Choose a dataset in the catalogue under Data Explorer.
  2. Use the search box to search every visible field.
  3. Use the column filter to restrict the table to records matching a value.
  4. Click a column heading to sort ascending or descending.
  5. Download the filtered result as CSV and open it in Excel.
  6. Use Overview & visualisations for dataset coverage and selected analytical charts.

What the data mean

Each CSV is a distinct evidence layer. Do not add together PNRR allocations, Ministry budget economies, Treasury transfers, private VC co-investment and R&D performance. The documentation in the repository explains the accounting and additionality rules.
